Example audit: tone discrimination learning

A made-up two-page paper on mice learning a tone discrimination.

This audit covers the Results, with Methods as the description each result is checked against. Each claim is marked in the text with an ID, and has a card that sets what Results, Methods, the code, and the data say about it side by side, with the exact text, line, or value behind each statement.

Manuscript
materials/manuscript.txt, two pages. Quotes are from its text; page numbers refer to it.
Code
materials/code/analysis.py, with its checksum in the manifest.
Data
materials/data/trials.json: 3,540 trials, with its checksum in the manifest.
Recomputation
Trial counts and accuracies were recomputed from the data by derivations/values_trials.py.
